## 训练方法详解

### 1. 训练类型：**继续预训练 (Continual Pre-training)**

```python
# 核心代码（第 133-138 行）
dataset = Dataset.from_dict({
    "input_ids": all_chunks,    # 输入
    "labels": all_chunks.copy(), # 标签 = 输入（完全相同！）
})
```

**关键特点：**
| 特征 | 说明 |
|------|------|
| **数据格式** | 纯文本（无问答对） |
| **学习目标** | `input` → 预测下一个 token |
| **labels** | 与 input 完全相同 |
| **本质** | 让模型学会"续写中医文本" |

### 3. 为什么效果"变差"了？

#### 原因 1：**任务目标完全不同**

| 模型 | 训练目标 | 输出风格 |
|------|---------|---------|
| **原模型** | 通用问答 | 直接回答问题 |
| **微调模型** | 文本续写 | 背诵/抄写经典原文 |

你的问题："腹胀可以刺什么穴位？"

| 模型 | 理解方式 | 回答 |
|------|---------|------|
| 原模型 | 这是一个**问题**，需要回答 | 直接列穴位 |
| 微调模型 | 这是一个**开头**，需要续写 | 从《针灸甲乙经》开始抄写 |

---

#### 原因 2：**灾难性遗忘 (Catastrophic Forgetting)**

```
原模型知识：
├── 通用知识（语言、常识）
├── 问答能力
└── 中医知识（少量）

继续预训练后：
├── 通用知识 ⬇️ 被弱化
├── 问答能力 ⬇️ 被破坏
└── 中医知识 ⬆️ 增强
```

模型为了学会中医文本的**语言模式**，牺牲了原有的**问答能力**。

---

#### 原因 3：**评估方式错误**

你用**问答**的方式评估一个**续写**模型：

```python
# 你问：
"腹胀可以刺什么穴位"

# 模型认为：
"这是一个开头，我需要从中医经典里续写一段文本"
```

## 如何改进？

### 方案 1：**SFT 监督微调**（推荐）

准备**问答对数据**：

```json
{"instruction": "腹胀可以刺什么穴位？", "output": "足三里、中脘、内关..."}
{"instruction": "头痛可以刺什么穴位？", "output": "百会、风池、合谷..."}
```

训练目标：学习 **问题 → 答案** 的映射

### 方案 2：**Prompt Engineering**

微调模型需要正确的"触发格式"：

```
请用中医知识回答：
问题：腹胀可以刺什么穴位？
答案：
```

### 方案 3：**混合策略**

- 继续预训练 → 注入领域知识
- SFT → 学习问答格式
- RAG → 检索相关经典原文
